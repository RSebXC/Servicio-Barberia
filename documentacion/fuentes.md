# Fuentes técnicas

Consultadas el **6 de noviembre de 2026**. Se utilizaron fuentes oficiales para comprobar capacidades que respaldan la propuesta. La elección del stack, objetivos de calidad y diseño del motor son recomendaciones del proyecto, no conclusiones prometidas por los proveedores.

| Fuente | Uso en la documentación |
| --- | --- |
| [Next.js — Route Handlers](https://nextjs.org/docs/app/getting-started/route-handlers) | API HTTP dentro de la aplicación |
| [Next.js — Deploying](https://nextjs.org/docs/app/getting-started/deploying) | Servidor Node.js/contenedor y limitaciones de exportar solo estáticos |
| [PostgreSQL — Explicit Locking](https://www.postgresql.org/docs/current/explicit-locking.html) | Base para controlar concurrencia mediante bloqueos |
| [Prisma — Transactions](https://www.prisma.io/docs/orm/fundamentals/transactions) | Transacciones en el acceso a datos; revisar versión antes de programar |
| [Neon — Managed Better Auth](https://neon.com/docs/auth/overview) | Opción propuesta de identidad administrada del personal |
| [Neon — Auth production checklist](https://neon.com/docs/auth/production-checklist) | Configuración necesaria de dominio/correo antes de producción |
| [MDN — SpeechSynthesis](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis) | Voz y disponibilidad de voces del dispositivo |
| [MDN — Autoplay guide](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay) | Restricciones de reproducción de audio y prueba con interacción inicial |

Los precios de proveedores, versiones de paquetes, condiciones de planes, compatibilidad de regiones y soporte específico del equipo deben verificarse de nuevo al implementar/contratar. Esta consulta no incluyó una cotización comercial ni pruebas de rendimiento o compatibilidad sobre los equipos de la barbería.

La fuente de los acuerdos de negocio es [contexto.txt](../contexto.txt) más las aclaraciones de la conversación recogidas en [decisiones](05-planificacion/decisiones-pendientes.md). El contexto original se conserva sin alteraciones.
